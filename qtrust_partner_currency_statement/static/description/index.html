Q-Trust Partner Currency Statement

Customer and vendor movements in one selected currency

View an interactive partner statement from Accounting with company, partner, currency, and date filters. Review opening balance, period debit and credit, and closing balance in a single screen.

Key features

  • Customer or vendor statement from Accounting reporting.
  • Filter by partner, active company, currency, and date period.
  • Review opening balance, debit, credit, and closing balance.
  • Search within displayed transaction rows.
  • Export statement lines to XLSX and print a PDF report.
  • Designed as an additional report; it does not replace standard accounting reports.

Compatibility

Version: Odoo 19.0

Dependency: Accounting (account)

License: LGPL-3

Important: Validate the module in a test database before production use, especially multi-company access, foreign-currency settlements, reconciliations, PDF output, and spreadsheet exports.
